# Sessão 22: perfil (foto, links com logo) e saída das tecnologias — plano

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** foto de perfil enviada pela própria pessoa e mostrada onde hoje há iniciais; GitHub/LinkedIn/calendário como cartões com logos oficiais; tecnologias e habilidades fora do sistema, com os dados.

**Architecture:** backend grava `<uuid>.webp` em `ANEXOS_DIR/fotos/` e o nome em `usuarios.foto` (migração 016); `GET /fotos/:arquivo` é público, com cache imutável. Frontend recorta no `canvas`, envia 256×256 WebP em bytes crus (mesmo mecanismo dos anexos) e troca `Av`/avatar do topo/avatar do perfil por um componente `Avatar` que cai nas iniciais.

**Tech Stack:** back Express + TypeScript + `pg` + Jest; front React 18 (JS) + Vite + Bootstrap, testes `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-18-perfil-design.md` (ler antes de qualquer tarefa).

## Global Constraints

- Back: `~/BackendProjetosERP`, front: `~/FrontendProjetosERP`, branch `feat/perfil` nos dois. Um PR por repositório.
- Antes de cada commit: `npm run lint && npm run format:check` (sem pipe) no repo tocado; testes da tarefa passando.
- Commits: Conventional Commits em português, imperativo, até 72 caracteres, escopos `pessoas`, `ui`, `infra`, `anexos`; migração = `db`. Rodapé `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Erros: `ErroValidacao` (400) com mensagem em `mensagensDeErro.ts` dizendo o que está errado; nunca 500 por entrada inválida.
- Foto: entrada no navegador JPEG/PNG/WebP até **5 MB**; saída **256×256 WebP**; backend aceita só assinatura `RIFF????WEBP` e até **300 KB** (`300 * 1024`).
- Nome do arquivo: `^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}\.webp$` (UUID v4 minúsculo do `uuid`).
- `GET /fotos/:arquivo`: sem login; `Content-Type: image/webp`, `X-Content-Type-Options: nosniff`, `Cache-Control: public, max-age=31536000, immutable`, `Cross-Origin-Resource-Policy: same-site`, `Content-Disposition: inline`; nome inválido ou inexistente = 404 `{ message: "Foto não encontrada." }`.
- Ninguém é excluído (ADR-006): inativar não mexe na foto.
- Logos fiéis aos oficiais, nas cores da marca, SVG embutido (sem CDN): GitHub Invertocat (`currentColor`, segue o tema), LinkedIn "in" em `#0A66C2`, Google Agenda colorido só para `calendar.google.com` e `calendar.app.google`; outro calendário = ícone genérico.
- Telas responsivas (375 px), claro e escuro, visual Halo. Responsivo só em `src/styles/responsive.css`.
